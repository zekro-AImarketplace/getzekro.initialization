#  ZEKRO Token — Fueling the Decentralized AI Economy

Welcome! This is the official TypeScript module for the **ZEKRO Token** — the core utility and governance token for our decentralized AI model marketplace.

We created ZEKRO to give developers something they don’t usually get in AI: **real ownership and real rewards**.  
You can use it to **license models**, **stake in the ecosystem**, **govern the platform**, or **earn royalties** from usage — all without relying on a centralized provider.

We’re also proud to say we’re **backed by Anthropic AI**, so our project benefits from cutting-edge model safety, alignment principles, and infrastructure.

---

##Token Utility

This repo contains a simple but functional simulation of how ZEKRO could work on-chain.  
It includes:

- Token transfers  
- Staking support  
- Pay-per-use licensing for AI models  
- Usage history tracking  

It’s written in **TypeScript**, so you can use it in apps, simulations, or even testnets and browser environments.

---

##  How ZEKRO Works

- You publish your AI model (imagine pushing it like code)
- It’s minted as a token (like an NFT)
- You set the licensing terms (pay-per-use, subscriptions, etc.)
- Other users can run your model and pay with ZEKRO
- You get paid automatically — no middlemen
